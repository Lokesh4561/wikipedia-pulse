      How it works

      Every hour, this pipeline runs by itself from Wikimedia's public data to this page.

      1. Wikimediahourly dumps
      2. GitHub Actionslands files
      3. BronzeAuto Loader
      4. Silverparsed + checked
      5. Goldtrends + spikes
      6. This pagehourly export

      Delta Lake tables on Databricks, orchestrated by a Databricks Workflow on serverless compute. The code, design notes and tests are on GitHub.

      Built by Lokesh Reddy Maddali. Data: Wikimedia pageview dumps (CC0). Times are in IST.
